# Cardano Treasury Explorer Open Data Source - ADAspending.com - Milestone 4

**Project Catalyst Fund 14 — Project 1400032**  
**Milestone:** Back-end programming + Blockchain integration

ADAspending has completed the backend and Cardano integration work for Milestone 4. The platform is live, and its dashboard now presents current Cardano treasury information to the community.

The backend is deployed on Google Cloud and connected to the ADAspending website.

### (B) Cardano integration

ADAspending retrieves Cardano mainnet data and displays treasury and supply information with its source and update status.
